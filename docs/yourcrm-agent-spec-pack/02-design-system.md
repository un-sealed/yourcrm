# 02 — Design System & Shared UI

## Goal

Build the shared UI layer so feature agents do not invent different patterns.

## Design principles

- Dense but readable CRM UI.
- Fast keyboard interactions.
- Strong hierarchy.
- Responsive from desktop to mobile.
- Light and dark themes.
- Accessible by default.
- Minimal visual noise.

- saved layouts

## Accessibility

- keyboard navigation
- visible focus
- semantic labels
- screen-reader support
- color-independent status indicators
- reduced-motion support
- WCAG-oriented contrast

## Acceptance criteria

All core components have stories/examples, tests, responsive behavior and dark/light theme support.
