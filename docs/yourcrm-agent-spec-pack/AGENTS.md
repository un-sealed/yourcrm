# YourCRM Agent Instructions

- Product specifications in this directory are the source of truth for feature scope.
- Read `README.md`, `AGENT-DEPENDENCIES.md`, and the assigned module before coding.
- Preserve shared contracts.
- Security and permission checks are mandatory.
- AI actions must inherit permissions and be auditable.
- Do not build a full ERP.
- Prefer mainstream libraries and simple architecture.
- Add tests with every feature.
